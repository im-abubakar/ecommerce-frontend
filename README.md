# Ecommerce Store – Full Stack eCommerce Web Application + Admin Panel

![Store URL]((https://www.sastamal.store/))

This is a modern full stack eCommerce web application built with **Next.js, Express.js, MongoDB (Mongoose), Redux Toolkit, RTK Query, Stripe, Bootstrap 5, and Sass**. It includes a **feature-rich admin panel** for easy management of your online store.

---

## 🚀 Features Overview

- **Next.js:** Fast, production-ready React framework for scalable web apps.  
- **Express.js:** Flexible Node.js framework for backend development.  
- **MongoDB & Mongoose:** Robust database with schema-based modeling.  
- **Stripe Integration:** Secure online payments.  
- **Nodemailer:** Send emails for registration, verification, and notifications.  
- **Authentication:** Google login, registration, email verification, forgot/reset password, profile updates.  
- **Redux Toolkit & RTK Query:** Efficient state management and data fetching.  
- **TypeScript + Next.js App Directory:** Reliable and maintainable code.  
- **Form Validation:** Ensures accurate data input.  
- **Bootstrap 5 & Sass:** Responsive and modern UI design.  
- **Responsive & Touch Friendly:** Works seamlessly on all devices.
